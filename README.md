# KerjaBersama

Voice-first, human-supported job-matching prototype for Malaysia.

## Quick start

Open `index.html` directly in a browser, or run a local server:

```bash
npm run dev
```

Then visit [http://localhost:3000](http://localhost:3000).

## Prototype flows

1. **Welcome** — Language selection (BM, English, 中文, தமிழ்) and role choice
2. **Job seeker** — Voice input → AI profile → Verified job matches → Apply
3. **Career Guide** — Match with Puan Aisyah for application help and interview practice
4. **Progress** — Timeline showing profile, application, guide support, interview
5. **Guide dashboard** — Pending requests, sessions, Legacy Score

## Design

- Mobile-first (430px max width)
- Malaysian public-service palette: navy, teal, white, yellow/red accents
- Large touch targets, plain Bahasa Malaysia, accessibility-friendly
